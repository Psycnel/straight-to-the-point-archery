Straight to the Point Archery Website

 Project Overview
This project is a responsive and accessible website for **Straight to the Point Archery**, designed to provide information about archery classes, private lessons, instructors, and contact details.

The goal of this website is to create a clean, user-friendly, and visually appealing platform** where users can easily explore services and learn more about archery training.

 

Website Purpose
- Provide information about archery programs and services  
- Help users find the right class or lesson  
- Introduce instructors and training environment  
- Allow users to contact the organization بسهولة  


 Features
- ✅ Responsive design (mobile, tablet, desktop)  
- ✅ Accessible navigation (skip links, focus states)  
- ✅ Optimized images for performance  
- ✅ Lazy loading for faster page load  
- ✅ Interactive UI (hover effects & animations)  
- ✅ Clean layout with modern design  
- ✅ Multiple pages:
  - Home
  - Classes
  - Private Lessons
  - Instructors
  - About Us
  - Contact
